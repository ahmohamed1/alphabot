Place an AprilTag image named "apriltag.png" in this folder.

- Recommended tag size: ~200x200 PNG.
- You can generate an AprilTag PNG (e.g., tag ID 0, family 36h11) using any Apriltag generator and save as apriltag.png.

After adding the image, refresh Gazebo or re-insert the model to see the tag texture applied to the front face.
